ZARYA BOT BRANDING — drop your images here, then run set_branding.bat

AVATAR  -> save as  avatar.png  (or .jpg / .gif)
  - Square. 1024x1024 ideal (Discord shows it as a circle, keep her face centered).
  - Under 10 MB. Animated .gif works too.

BANNER  -> save as  banner.png  (or .jpg / .gif)
  - Wide. 960x540 ideal (16:9). Discord crops to a ~2.83:1 strip, so keep the
    important stuff in the middle horizontal band.
  - Under 10 MB.

You can provide just one or both — the script only sets what it finds.

When the files are in this folder, double-click  set_branding.bat  (one level up,
in the ZaryaBot folder) OR tell Zarya in the terminal and she'll run it.

NOTE: Discord rate-limits bot avatar changes to a couple per hour, so we set it
once and get it right.
