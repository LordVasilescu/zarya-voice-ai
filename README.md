# Zarya — Discord Voice AI Partner

Zarya is a voice-first AI companion that joins a Discord voice channel, listens to everyone in
it, transcribes speech locally with Whisper, thinks with Claude (via the Claude Code CLI), and
talks back in a locally cloned voice generated by Chatterbox TTS. A separate web console gives
the same assistant a custom chat UI on the desktop.

The project is split into three parts:

| Folder     | What it is |
|------------|------------|
| `bot/`     | Node.js Discord bot: voice capture, wake-word routing, group memory, replies |
| `voice/`   | Python local speech server: Whisper STT + Chatterbox voice-cloning TTS on the GPU |
| `console/` | Zero-dependency Node.js web console that streams Claude Code output into a custom UI |

## Features

**Discord bot (`bot/`)**
- `!zarya join | leave | reset | forget | status` text commands.
- Captures each speaker as a **separate Opus stream**, so attribution stays exact even when
  people talk over each other; decodes to PCM with `prism-media` and resamples with `ffmpeg`.
- Sends each utterance to the local `/stt` endpoint and filters common Whisper hallucinations
  on near-silence.
- **Wake word** routing: everything is logged, but only lines containing "Zarya" (plus common
  mis-transcriptions) are sent to the model.
- **Consented group memory**: posts a disclosure when joining, appends timestamped JSONL
  transcripts per day, primes a rolling context buffer on restart, and offers `!zarya forget`
  to wipe the day's log. Raw audio is discarded unless `ZARYA_KEEP_AUDIO=1`.
- Uses the Claude Code CLI headlessly with `--resume` so the conversation persists; persona and
  reply format are defined in `bot/CLAUDE.md`.
- Structured reply protocol: a short spoken part, an optional `---PUBLISH---` markdown section
  posted to an archive channel (split at Discord's length limit, `IMAGE:` lines downloaded and
  attached), and `MUSIC:` lines that are forwarded as `!it` commands to a companion music bot.
- Speaks replies by requesting a WAV from `/tts`, encoding Opus with `ffmpeg`, and playing it in
  the voice channel.
- `set_branding.mjs` sets the bot's avatar, banner, and About Me via the Discord REST API.

**Voice server (`voice/`)**
- `GET /health`, `POST /tts {text}` -> WAV, `POST /stt <wav>` -> `{text}`.
- Chatterbox TTS cloned from a reference clip; long text is chunked by sentence for quality;
  per-request `exaggeration` / `cfg` / reference overrides for voice tuning.
- Whisper loads lazily on first STT call; a lock shares the GPU between STT and TTS.
- `make_reference.py` generates reference clips from the Hume TTS API.

**Web console (`console/`)**
- Spawns the Claude Code CLI in `stream-json` mode and forwards each NDJSON event to the
  browser, rendering text and tool-use chips live; keeps one continuous session with `--resume`.
- Static file serving with path-traversal protection; `/api/reset` starts a fresh session.

## Architecture

```
Discord VC --opus--> bot/ --wav--> voice/ /stt (Whisper) --text--> bot/
                       bot/ --prompt--> claude CLI --reply--> bot/
                       bot/ --text--> voice/ /tts (Chatterbox) --wav--> ffmpeg --opus--> Discord VC
```

## Tech stack

Node.js, discord.js v14, @discordjs/voice, prism-media, ffmpeg, Python, PyTorch (CUDA),
OpenAI Whisper, Chatterbox TTS, Claude Code CLI, vanilla HTML/CSS/JS.

## Setup

Prerequisites: Node.js 20+, Python 3.11+, `ffmpeg` on PATH, an NVIDIA GPU (CPU works but slowly),
and the Claude Code CLI installed and signed in.

**1. Voice server**
```bash
cd voice
python -m venv venv
venv\Scripts\activate            # or: source venv/bin/activate
pip install -r requirements.txt
# Provide your own reference clip as voice/ref_neutral.wav (or set ZARYA_REF),
# e.g. generate one with make_reference.py (needs HUME_API_KEY).
python zarya_server.py           # listens on 127.0.0.1:8765
```
Env (optional): `ZARYA_REF`, `ZARYA_PORT`, `ZARYA_EXAGGERATION`, `ZARYA_CFG`, `ZARYA_WHISPER`.

**2. Discord bot**
```bash
cd bot
npm install
cp .env.example .env             # set DISCORD_TOKEN
npm start
```
Enable the *Message Content* intent for the bot in the Discord Developer Portal.

**3. Web console (optional)**
```bash
cd console
node server.js                   # http://localhost:8788
```
Env (optional): `ZARYA_CONSOLE_PORT`, `ZARYA_WORKDIR`, `CLAUDE_PATH`.

> Voice reference audio and recorded conversations are intentionally not included in this
> repository.
